📖 使用教程（按住这条标题栏可以拖到任意位置） — ✕

① 先让编辑器读到游戏数据

  1. 双击 打开地图种子编辑器.bat → 启动器里选一份 regulation.bin → 点【读取】
  2. 读完点【打开编辑器网页】（读一次要几秒，进度条走完再点）
  3. 以后改过 bin、或换了别的 bin → 双击 刷新数据.bat 重新生成数据

② 改一颗种子（最常用）

  1. 右上 ① 先选「哪个夜王 × 哪种地形」→ 选中一颗种子 → 点【载入这个种子】
  2. 地图上哪里想改就点哪里，右边面板点一下就能换：
    • ③ 第 1 夜 / 第 2 夜的 boss
    • 夜战缩圈：点地图上的圈 → 换这一夜打哪片区域
    • 据点：点据点 → 换类型和属性。名字长这样：遗迹（毒）·营地（发狂）·教堂（圣）
      · 据点分两族，只能在自己这一族里换：
      　地块族＝要塞 · 营地 · 遗迹 · 教堂 · 锻造村 · 粪坑
      　点位族＝魔法师塔 · 古老魔法师塔 · 血瓶教堂 · 高级村落商人 · 小营地 · 车队 · 小屋
      · 粪坑／锻造村／小营地／车队／小屋 游戏里没有图标素材 ⇒ 地图上直接写成文字
    • 出生点：点那个小人 → 换落地位置
  3. ⑦ 山羊交易、⑧ 特殊事件（一张图可挂多个事件，可选第 1 天 / 第 2 天）
  4. 改完不用马上导出：⑨ 会自动把改动存住（换种子、刷新页面都不丢）
  5. 改够了 → ⑨ 点【一次导出全部已修改】→ 一次出全（按表合并成 3 份 CSV）

③ 导入 Smithbox（关键：覆盖的行⛔不能勾 Append）

  1. 先备份：把 regulation.bin 复制一份留着（改坏了直接换回来）
  2. 用 Smithbox 打开这份 bin（NR 的 bin 是加密壳，只能靠 Smithbox 保存）
  3. 左边点中对应的表 → 菜单 Tools ▸ Data Transfer ▸ Import ▸ Import from file
  4. 选对应 CSV（文件名里就写着表名）：
    • LotResultSmallBaseAndSpot_*.csv → 表 LotResultSmallBaseAndSpot（据点排布）
    • LotResultPlayAreaParam_*.csv → 表 LotResultPlayAreaParam（缩圈 / 夜boss 指向）
    • LotResultMapPatternFlag_*.csv → 表 LotResultMapPatternFlag（事件 / 第几天 / 出生点）
  5. ⛔ 我们的 CSV 全是「改现有行」⇒ 不要勾 Append New Rows（勾了整份不生效）
  6. 三份都导完 → 按 Ctrl+S 保存
  7. 进游戏验证：出击时用锁定工具锁住那张图（例：地图排布锁定器.bat）

④ 常见问题

  • 编辑器显示有、进游戏没效果 → 十有八九是导入时勾了 Append；覆盖的行一定不勾
  • 改了好多张图 → 别一张张导，用 ⑨【一次导出全部已修改】
  • 换了 bin、刷新过数据 → ⑨ 先【清空全部暂存】再改（行序号会变）
  • 大空洞（DLC） 本次不做，界面上也不给改
  • 地图显示太乱 → 用 ④ 那一排勾选框，不看的关掉
  • 这个教程窗挡路 → 点窗上的 — 缩成小按钮；要彻底关掉就点最上面的【📖 使用教程】
